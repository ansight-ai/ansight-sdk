# Core SDK test apps

Broad integration harnesses for the Ansight SDK. Local project files reference
SDK source in this repository through relative paths.

| App | Platform |
| --- | --- |
| [Android](android/) | Native Android |
| [iOS](ios/README.md) | Native iOS |
| [Capacitor](capacitor/README.md) | Capacitor on Android and iOS |
| [Flutter](flutter/README.md) | Flutter on Android, iOS, and macOS |
| [.NET](dotnet/) | .NET MAUI and native Android, iOS, and Mac Catalyst |

Feature-specific SDK tests belong under their named suite, such as
[`motion`](../motion/README.md).
